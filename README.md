A zero-knowledge, privacy-preserving cryptographic audit trail for software authorship. Code Provenance Tracker deterministically tracks whether code was hand-typed, pasted from clipboard, generated by AI copilots, or inserted via native inline suggestions, securing metadata into an immutable SHA-256 hash chain and attaching it to Git commits via `refs/notes/provenance`.

## Features
- **Deterministic AI Interception**: Direct tracking of native VS Code inline suggestions (GitHub Copilot, Cursor, Tabnine).
- **Function-Level Nutrition Labels**: CodeLens indicators above functions displaying human vs. AI distribution.
- **Tamper-Evident Hash Chain**: Genesis-anchored SHA-256 cryptographic sequence verifying keystroke histories.
- **Git Notes Anchoring**: Code-free metadata snapshots attached to commits under `refs/notes/provenance`.
- **CI/CD Gatekeeper**: Automated GitHub Action failing Pull Requests exceeding configurable AI thresholds or containing tampered chains.
- **Zero-Knowledge Privacy**: Only aggregates, timestamps, and line counts are recorded—never source code or clipboard contents.
